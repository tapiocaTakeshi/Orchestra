# Modern UI Layer

このプロジェクトに **追加導入** されたモダンUIレイヤーです。既存のスタイルは破壊しません。

## 構成
- `styles/modern-ui.css` — デザイントークン（色 / 余白 / 角丸 / 影 / モーション / タイポ）と `.mui-*` ユーティリティ
- `components/ui/Button.tsx` — `primary` / `secondary` / `ghost` の3種
- `components/ui/Card.tsx` — エレベーション + ホバーリフト、`glass` プロップでガラス調
- `components/ui/Container.tsx` — 流体最大幅コンテナ
