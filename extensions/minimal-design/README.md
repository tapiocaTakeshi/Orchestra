# Minimal Design

シンプルで余白を活かしたミニマルデザインテーマ。

## 特徴
- 低彩度のカラーパレット
- タブはアクティブ下線のみで強調
- 細めのスクロールバー、やわらかい影
- 角丸・余白を統一した UI コンポーネント
- Light / Dark の両モード

## 使い方
1. コマンドパレットを開く（`Cmd/Ctrl + Shift + P`）
2. `Preferences: Color Theme` を実行
3. **Minimal Light** または **Minimal Dark** を選択

## カスタム CSS（任意）
さらに UI を細かくチューニングしたい場合は、`Custom CSS and JS Loader` などの拡張で
本拡張に同梱されている `media/minimal-theme.css` を読み込んでください。
