# Minimal Zen Theme

A minimal, whitespace-focused color theme bundled with the editor.

The theme reduces visual noise by:

- Removing tab and panel background contrast (flat surface)
- Using a single thin underline for the active tab and active activity bar item
- Collapsing borders to a single hairline (`#eaecef` light / `#21262d` dark)
- Muting the status bar to a secondary text color
- Limiting accent colors to two roles (foreground + a single blue link accent)

Two variants are provided:

- **Minimal Zen Light** — paper-like background `#ffffff`
- **Minimal Zen Dark**  — ink-like background `#0d1117`

Activate via `Preferences: Color Theme` (`Ctrl+K Ctrl+T`).
