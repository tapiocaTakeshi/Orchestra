I'm building an AI chat app using Electron. I want the design to be extremely minimal. No heavy borders, no cluttered headers. How should I approach the UI?

To achieve a truly minimal aesthetic in an Electron app, the key is to rely on whitespace and typography rather than explicit structural elements like borders or backgrounds.

Here are three core principles for this approach:

1. Frameless Window
Hide the OS default title bar and implement a custom `-webkit-app-region: drag` area. Blend it seamlessly into your layout so the app feels like a single continuous surface.

2. Typographic Hierarchy
Use font weight, size, and subtle color shifts (like grays instead of stark black) to differentiate UI components. Remove unnecessary dividing lines.

3. Contextual Input
The text input should float elegantly at the bottom. Use a very subtle box-shadow instead of a harsh border to indicate the input area, keeping focus purely on the text.
