# チャットデザイン変更内容まとめ

## 概要
`SidebarChat.tsx` のチャット UI は、**Minimal / Modern** を意識して、全体的に以下の方向で整理されています。

- 装飾を増やしすぎず、**余白・階層・透明感**で情報を見せる構成
- 入力欄・送信ボタン・メッセージ表示を、より**軽く洗練された印象**に調整
- スクロール中やストリーミング中の状態変化を、**視線移動が少ない自然なアニメーション**で表現
- 初回表示時の導線や提案プロンプトを見直し、**使い始めやすさ**を向上

---

## 適用した主なデザイン変更点

### 1. 入力エリアの刷新
`VoidChatArea` を中心に、入力欄まわりをモダンなカード型に調整しています。

- 角丸を強めたコンテナに変更
- 単色ではなく、**淡いグラデーション背景**を採用
- `backdrop-blur` と繊細な border / shadow を追加
- hover / focus 時に境界線とシャドウが自然に変化
- 下部の操作列（モデル切替、添付、送信）を**半透明の補助バー**として分離

**操作感の変化**
- 入力可能領域が視覚的にわかりやすくなっています
- フォーカス時に「今ここに入力している」感が明確です
- 付属操作が本文入力と干渉しづらくなっています

---

### 2. 送信 / 停止ボタンのビジュアル改善
`ButtonSubmit` / `ButtonStop` は、白基調の立体感ある丸ボタンに変更されています。

- 送信ボタン:
  - 明るいグラデーション
  - hover 時に軽く拡大
  - 押下時に縮むアニメーション
- 停止ボタン:
  - 同系統の見た目で統一
  - pulse 系の演出を追加し、**実行中であること**を視認しやすく変更

**操作感の変化**
- 送信・停止の切り替わりがわかりやすいです
- CTA としての視認性が高くなっています

---

### 3. ドラッグ & ドロップの視覚フィードバック追加
入力エリアへのファイルドロップ時、オーバーレイが表示されるようになっています。

- 青系のハイライト
- dashed border
- 中央に「ここにファイルをドロップ」のラベル表示
- Paperclip アイコンで用途を明示

**操作感の変化**
- ドロップ可能状態が即座に認識できます
- 画像やファイル添付の発見性が上がっています

**注意**
- hidden file input の `accept='image/*'` により、手動添付 UI は現状画像寄りです
- 一方で DnD 側では非画像ファイルも `File` として取り込む設計です  
  → **添付導線ごとに扱いが少し異なる**点は認識しておくとよいです

---

### 4. ユーザーメッセージの Sticky Stack 表現
ユーザーの過去メッセージが、スクロール時に上部へ貼り付く `sticky` 表現になっており、さらに**重なりの深さ**を持つ演出が追加されています。

- pinned 状態を `IntersectionObserver` で検出
- 古いメッセージほど
  - scale down
  - opacity 減衰
  - 軽い blur
  - z-index 調整
- 現在アクティブな先頭メッセージは、よりはっきり表示

**操作感の変化**
- 会話の文脈を保ったままスクロールできます
- 直近のユーザープロンプトを見失いにくいです
- 単なる固定表示よりも自然で、情報の重なり方に奥行きがあります

**注意**
- 長文ユーザーメッセージは sticky 時に 2 行クランプされます
- 全文確認は編集モードへ入るか hover title を使う想定です

---

### 5. スクロール操作の改善
`ScrollToBottomContainer` により、自動スクロール挙動がより丁寧に制御されています。

- ユーザーが下端から十分離れた場合、**自動追従を停止**
- 明示的に最下部へ戻るまでは streaming でも引き戻されない
- 「Jump to latest」ボタンを下部中央に表示

**操作感の変化**
- 読み返し中に勝手に最下部へ飛ばされにくくなりました
- ストリーミング出力中でも過去メッセージを安心して読めます

---

### 6. Reasoning / Flow 表示の整理
思考中・処理中の状態は、派手すぎないミニマルな表示へ寄せています。

#### ReasoningWrapper
- 小さなドットの pulse アニメーション
- `思考中` / `○秒間思考しました` の表示
- 開閉可能なセクション化

#### FlowIndicator
- 実行フェーズを簡潔なラベルで表示
  - 思考中
  - 検索中
  - 読み込み
  - 実装中
  - 実行中

**操作感の変化**
- 「今何をしているか」が一行で把握しやすいです
- 長いストリームでも状態理解しやすくなっています

---

### 7. ランディング画面の改善
初回表示時の案内が、余白多めのシンプルな構成に整理されています。

- セクションラベルを追加
- 提案プロンプトをカード風ボタンで表示
- 各提案に
  - アイコン
  - 補足ヒント
  - hover アニメーション
  - 軽いフェードイン演出
- 過去スレッドがある場合はおすすめではなく履歴を優先表示

**操作感の変化**
- 初見ユーザーが次に何をすればよいか理解しやすいです
- 提案文をそのまま送れるため、最初の一歩が軽くなっています

---

### 8. ヘッダーとログイン導線の整理
上部ヘッダーはより簡潔になっています。

- ログイン / サインアウトを右上に配置
- 設定ボタンに hover アニメーション追加
- サインイン前は、中央オーバーレイでログインを促す UI を表示

**操作感の変化**
- 認証状態が把握しやすいです
- 設定やログインへの導線が見つけやすくなっています

---

### 9. 変更内容サマリー / Command Bar 表示の整理
ファイル変更一覧や一括承認 / 一括拒否まわりは、全体に合わせて整理されています。

- 上部バーをコンパクトに維持
- 展開可能なファイル詳細
- 状態インジケータを継続表示
- チャットログコピーのフィードバック追加
  - copied
  - error

**操作感の変化**
- エージェント編集後の確認導線がわかりやすいです
- 状態確認と一括操作がしやすくなっています

---

## 利用上の注意

### 1. 編集中メッセージは 1 件のみ
ユーザーメッセージ編集は、同時に複数開かないよう制御されています。

- 新しいメッセージを編集すると、他の編集中メッセージは閉じます

### 2. Sticky 表現と編集モードの相性
編集モードのカードも sticky stack に参加します。

- 奥に下がった edit card は `pointer-events: none` になるため、誤操作は起きにくいです
- ただし、スクロール位置次第で「編集対象が上部に固定される」見え方になる点は理解が必要です

### 3. 長文プロンプトは折りたたまれる
表示モードでは 2 行クランプのため、長文は省略されます。

- 内容確認を重視するユーザーには、全文閲覧導線の追加余地があります

### 4. 添付導線の仕様差
- DnD: 画像以外のファイルも扱える
- クリップボタン: 現状 `image/*` 指定

この差は、ユーザーによっては挙動差として感じる可能性があります。

### 5. 透明・ぼかし表現への依存
`backdrop-blur` や `color-mix` を使った表現が多く含まれています。

- 環境やテーマによってはコントラスト差が出る可能性があります
- 特に dark / high-contrast 系では再確認推奨です

## 今後の調整ポイント

### 優先度高
1. **テーマ互換性の確認**
   - VS Code テーマ差分で border / bg / focus 表現が崩れないか確認
   - high contrast 対応も検討

2. **添付仕様の統一**
   - クリップボタンからも非画像ファイルを添付できるようにするか検討
   - UI 文言も `Attach image` から一般化できる

3. **sticky メッセージの可読性調整**
   - 長文クランプが厳しすぎる場合、1/2/3行や hover preview の最適化余地あり
   - stack の縮小率・blur 量は環境次第で微調整候補

### 優先度中
4. **ランディング画面の提案文ローカライズ**
   - 現状英語提案が混ざっているため、日本語 UI に合わせて統一可能

5. **フロー表示の視認性向上**
   - 現状はテキスト中心のため、必要ならステップチップ化も可能
   - ただし Minimal 方針とのバランスは要確認

6. **送信ボタンのアイコン色制御**
   - `IconArrowUp` の `fill="black"` はテーマによって浮く可能性あり
   - CSS 変数ベースへの置き換え余地あり

### 優先度低
7. **マイクロアニメーションの抑制オプション**
   - フェード・pulse・hover 拡大を減らしたいユーザー向けに軽量化設定を検討可能

8. **空状態の情報設計拡張**
   - 「最近使った操作」「テンプレート」「チュートリアル」導線の追加余地あり

---

## まとめ
今回の変更では、チャット UI 全体を **「情報密度は高いが、見た目は軽い」** 方向へ寄せています。  
特に以下が大きな改善点です。

- 入力欄の存在感と使いやすさの向上
- sticky stack による会話文脈の保持
- ストリーミング中の読みやすさ改善
- 初回利用時の導線整理
- ログイン / 添付 / 変更確認など補助操作の発見性向上

一方で、**テーマ差分・添付仕様差・sticky クランプ挙動**は今後の微調整候補です。  
Minimal / Modern の方向性としてはかなり一貫しており、今後は**視認性と一貫性の最終調整**が中心になる見込みです。
