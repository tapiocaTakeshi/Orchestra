# サイドバーAIチャット改善：実装設計

本ドキュメントは、ElectronアプリケーションにおけるサイドバーAIチャットのデザイン改善（Glassmorphism）およびフローの視覚的明確化を目的とした実装設計書です。

## 1. 目的と実装方針
- **目的**: 視覚的な洗練（Glassmorphism採用）と、AIチャットのステータス把握の容易化（フローの明確化）。
- **前提**:
    - フレームワーク: Electron + React + Tailwind CSS を想定。
    - ブラウザ環境: Chromium最新版（Glassmorphismの`backdrop-filter`をサポート）。

---

## 2. 実装計画 (Wave形式)

### Wave 1: UI デザイン刷新 (Glassmorphism)
*   **目的**: サイドバーに透過エフェクトを適用し、モダンなルック＆フィールを実現する。
*   **owner**: Frontend Engineer
*   **入力**: 現状のサイドバーコンポーネントコード
*   **出力**: Glassmorphismが適用されたサイドバーUI
*   **想定期間**: 1.5日
*   **実装詳細**:
    *   コンテナ背景に `bg-white/10` や `bg-black/20` と `backdrop-blur-md` を組み合わせたクラスを適用。
    *   境界線に `border border-white/20` を追加し、ガラス質感を強調。

### Wave 2: フロー可視化とUX改善
*   **目的**: AIチャットの各フェーズ（準備、思考中、生成中、完了）を視覚的に伝える。
*   **owner**: Frontend Engineer / Logic Engineer
*   **入力**: チャットの状態管理ロジック
*   **出力**: ステータスインジケータ付きチャットUI
*   **想定期間**: 1.5日
*   **実装詳細**:
    *   **思考中ステータス**: プログレスバーやドットアニメーションの表示。
    *   **生成中**: タイピングアニメーションの導入。
    *   **完了**: インタラクション（コピー、再生成ボタン）の明確な配置。

## 4. 技術的留意点とリスク対策

### 4.1. パフォーマンス対策 (重要)
*   **問題**: Glassmorphism (`backdrop-filter`) は重い処理であり、低スペックPCでは描画負荷が高くなる。
*   **対策**:
    *   複雑なアニメーションとの併用を避ける。
    *   `will-change: backdrop-filter` を適用し、GPUアクセラレーションを明示的に有効化する。
    *   レイヤー数を減らすために、可能な限り一つのコンテナで透過背景を完結させる。

### 4.2. 可読性・アクセシビリティ
*   **問題**: ガラス風透過背景は背景色に依存し、テキストが読みづらくなるリスクがある。
*   **対策**:
    *   テキストに適切なシャドウを付与する。
    *   背景となるアプリケーション側の色を暗め（Dark Mode）に統一し、テキストは白系（またはその逆）でコントラスト比を確保する。

### 4.3. クリティカルパス
1. **Glassmorphism のベース実装**（これが完了しないとUX改善の微調整ができない）
2. **状態管理ロジックの修正**（UX改善の要）

以上。本計画に基づき、直ちに実装フェーズへと移行する。
