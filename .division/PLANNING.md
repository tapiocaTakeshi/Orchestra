# 改修設計整理: SidebarChat デザイン刷新

`SidebarChat.tsx`のデザインを現代的で洗練されたものに引き上げるため、以下の設計方針で実装を進めます。

## 1. デザイン方針
*   **デザイン言語の統一**:
    *   **パディング**: 全体的に余白を整理し、余裕のあるレイアウトにする。
    *   **シャドウ**: コンポーネント単位で `shadow-sm` / `shadow-md` を活用し、階層構造（Depth）を表現。
    *   **角丸**: `rounded-lg` (8px/12px) を基本とし、ボタンやバッジは `rounded-full` や `rounded-md` を適宜組み合わせる。
*   **CSS トークンの活用**:
    *   既存の `void-*` 変数を継承しつつ、アクセントカラー（`--vscode-focusBorder`）との調和を図る。
    *   透明度（`bg-opacity`, `backdrop-blur`）を調整し、軽量感のある UI にする。

## 2. コンポーネント別詳細設計

| コンポーネント | 改善方針 |
| :--- | :--- |
| **`SidebarChat` 本体** | 全体の背景色を微調整し、`gap` を最適化して間延びを防ぐ。 |
| **`VoidChatArea`** | 入力エリアを強調。border-focus のトランジションを滑らかにし、底部ツールバーの背景との分離を明確化。 |
| **`ChatBubble`** | ユーザー/AI メッセージのコントラストを改善。カード型デザインの境界線に subtle なシャドウを追加。 |
| **`ToolHeaderWrapper`** | ツール実行時のヘッダーを、より情報密度を高めつつ整理されたレイアウト（左側アイコン＋右側アクション）に変更。 |
| **`CommandBarInChat`** | ファイル操作バッジのデザインを一新。ステータスインジケーターをより直感的に配置。 |

## 3. 共通スタイル・導入方針
*   **`ProseWrapper`**: タイポグラフィ設定の集約。`prose-sm` を基準にしつつ、行間（`leading-normal`）、フォントウェイト、マーカー色を調整。
*   **エフェクト**: ホバー時のトランジション（`transition-all duration-200 ease-in-out`）を全ボタンに適用。

## 4. 作業分解と優先順位

優先度が高い順に以下のフェーズで作業を行います。

### 【Phase 1】基盤整備（デザインシステムの適用）
1.  **Tailwind ユーティリティの整理**: 繰り返し使用されている `border-void-border-*` などをベースにコンポーネントを再定義。
2.  **`SmallProseWrapper` / `ProseWrapper` のリファクタリング**: 視認性を向上させるためのスタイル修正。

### 【Phase 2】核心 UI パーツの刷新
3.  **`VoidChatArea` のリデザイン**: 入力ボックス、ボタン、添付ファイル管理 UI の外観向上。
4.  **`ChatBubble` のデザイン刷新**: メッセージカードのスタイルを洗練させ、可読性を確保。

### 【Phase 3】ツール・ステータス管理 UI の洗練
5.  **`ToolHeaderWrapper` の UI アップデート**: 実行結果の折りたたみ・展開アニメーションとヘッダーレイアウトの最適化。
6.  **`CommandBarInChat` の改善**: 承認・拒否操作のフィードバック UI をよりモダンに。

### 【Phase 4】微調整
7.  **トランジションとホバーエフェクトの全適用**: UIの操作感を向上させるため、全体的なアニメーションの微調整。
