feat(sidebar-chat): redesign SidebarChat UI and bootstrap Electron Forge packaging

Summary
-------
Overhaul the Void SidebarChat look-and-feel around a shared design-token
system, harden the LLM message pipeline against mid-flight user
injections, and add Electron Forge so the app can be packaged/published.

SidebarChat redesign
- Introduce design tokens, style helpers and copy strings under
  src/vs/workbench/contrib/void/browser/react/src/sidebar-tsx/styles/
  (designTokens.ts, sidebarChatStyles.ts, sidebarChatStrings.ts,
  sidebarChat.css) so every surface/border/status color flows through a
  single source of truth aligned with --void-* / --vscode-* variables.
- Wire the new styles into SidebarChat.tsx and refresh the VS Code
  color themes (themes/*.json) to match the new palette.
- Expand chatThreadService.ts with the hooks required by the new UI
  (status/accent handling) without changing existing behavior.

LLM pipeline
- sendLLMMessage.impl.ts: add a takePendingInjection hook on the
  internal common params so orchestration can inject user text at
  phase boundaries; improve workspace file search with a JP→EN
  synonym map, a baseline manifest/entry allow-list, and a directory
  tree fallback when no keywords hit.
- sendLLMMessageService.ts / sendLLMMessageTypes.ts /
  sendLLMMessageChannel.ts / sendLLMMessage.ts: propagate the new
  injection channel end-to-end.

Packaging / tooling
- Add forge.config.js and the @electron-forge/* + electron-squirrel-startup
  dependencies (package.json, package-lock.json, forge.config.js).
- Bump extensions/open-remote-ssh to pick up the matching tooling.
- Update .vscode/settings.json for the new workflow.

Docs / assets
- Rewrite .division/*.md (CODER, DESIGNER, FILE-SEARCH, IDEAMAN,
  PLANNING, RESEARCH, REVIEW, SEARCH, WRITING) to describe the new
  SidebarChat spec and agent workflow; add
  .division/.orchestration-state.json.
- Replace src/chatgpt-info.html with a modern landing page using
  the new design language.
