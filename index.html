Features

開発のすべてを、ひとつの IDE に。

Division API による強力なオーケストレーションと、使い慣れた VS Code の操作性。 Orchestra は「AI と協働する開発」を標準にします。

Division API 統合

Anthropic・Google・OpenAI・Perplexity・xAI・DeepSeek — 6プロバイダー・38以上の最新 LLM をシームレスに利用できます。

役割ベースのマルチエージェント

Leader AI がタスクを分解し、コーディング・検索・設計・レビューを適材適所の AI にアサインします。

自律型エージェントモード

ファイル編集、ターミナル実行、プロジェクト管理からコードの実行まで、AI エージェントが自律的に行います。

インライン・コンテキスト追加

チャット中に @ を入力するだけで、ファイル・フォルダ・シンボルを文脈としてプロンプトに追加できます。

VS Code 完全互換

拡張機能、デバッグ、Git 連携など、使い慣れた VS Code の機能をそのまま利用可能です。

最高品質のアウトプット

複数の AI による並行・順次処理とクロスレビューで、単一モデルを超える品質のコードを生成します。

Division API

Orchestra の頭脳。

Division API は、Leader AI が指示を解析・タスク分解し、 複数の AI に並行・順次処理させるオーケストレーションシステムです。 MCP (Model Context Protocol) 連携にも対応しています。

API ドキュメントを見る
orchestra — flow 
// 1つのプロンプトから…
prompt: "認証機能を実装して"

leader  → タスクを分解
  ├─ search   → Perplexity Sonar
  ├─ design   → Gemini 2.5 Pro
  ├─ code     → Claude Sonnet 4.5
  └─ review   → GPT-4.1

// → 最高品質のコードが完成 ✨

AI の楽団と、開発を始めよう。

Orchestra はオープンソース。macOS / Windows / Linux で利用できます。
