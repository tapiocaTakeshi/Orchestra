# Trello 連携 — カードを自動でプロンプト実行する

Trello ボードの「実行待ち」リストに積まれたカードを、Orchestra が 1 枚ずつ取り出して
エージェントチャットのプロンプトとして実行する仕組みです。

実行が終わると、結果の要約をカードにコメントとして書き戻し、カードを完了リスト
（失敗時はエラーリスト）へ移動します。

```
Trello: TODO リスト
   │  ポーリング (既定 60 秒)
   ▼
Orchestra: カード → プロンプト組み立て
   │
   ▼
エージェントチャット (agent モード / ツール実行あり)
   │  完了を待つ (既定 30 分でタイムアウト)
   ▼
Trello: コメント書き戻し + Done / Error リストへ移動
```

## セットアップ

### 1. API Key と Token を用意する

1. https://trello.com/power-ups/admin で Power-Up を作り、**API Key** を発行する。
2. その API Key のページから **Token** を生成する（自分のアカウントに対して許可する）。

いずれも Orchestra の設定内に暗号化して保存されます（他の API キーと同じ扱い）。

### 2. Settings > Trello で設定する

| 項目 | 説明 |
| --- | --- |
| API Key / Token | 上で用意した認証情報。入力後「接続する」を押すとボード一覧を取得します |
| ボード | 監視対象のボード |
| 実行待ちリスト（必須） | ここに積まれたカードが実行対象になります |
| 実行中の移動先 | 実行開始時にカードを移すリスト。未指定なら移動しません |
| 完了時の移動先 | 正常終了時の移動先 |
| 失敗時の移動先 | エラー／タイムアウト／中断時の移動先 |

### 3. 実行条件を決める

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| カードを自動で実行する | オフ | オンにするとポーリングが始まります |
| ポーリング間隔 | 60 秒 | 下限 15 秒 |
| 1 回あたりの最大カード数 | 1 | 1 回のポーリングで処理する枚数。実行は必ず直列です |
| カードごとのタイムアウト | 30 分 | 超えるとエージェントを中断し、タイムアウト扱いにします |
| このラベルが付いたカードだけ実行 | なし | ラベル名で対象を絞りたいとき |
| カードごとに新しいスレッドを開く | オン | 前のカードの文脈を引きずらせたくない場合はオンのまま |
| 実行結果をコメントに書き戻す | オン | |
| ドライラン | オフ | プロンプトの組み立て結果だけ確認したいとき |

## プロンプトテンプレート

空欄なら組み込みのテンプレートを使います。差し替える場合は以下のプレースホルダが使えます。

| プレースホルダ | 中身 |
| --- | --- |
| `{{title}}` | カード名 |
| `{{description}}` | カードの説明 |
| `{{checklists}}` | チェックリストを `- [ ] 項目` 形式で展開 |
| `{{labels}}` | ラベル名をカンマ区切りで |
| `{{attachments}}` | 添付の名前と URL |
| `{{due}}` | 期限 |
| `{{url}}` | カードの URL |
| `{{cardId}}` / `{{boardName}}` / `{{listName}}` | カード ID / ボード名 / リスト名 |

## コマンド

コマンドパレット（`Ctrl+Shift+P`）から:

- `Trello: Run Pending Cards Now` — 今すぐ 1 回ポーリングして実行する
- `Trello: Toggle Automatic Card Execution` — 自動実行の ON / OFF
- `Trello: Cancel Running Card` — 実行中のカードを中断する

## 知っておくべき挙動

**ツールの自動承認が要ります。** エージェントがファイル編集やターミナル実行をするとき、
既定では承認ダイアログで止まります。無人で流すなら Settings > 機能オプション の
自動承認（edits / terminal / MCP tools）を有効にしてください。有効になっていない場合、
Trello タブに警告が出ます。承認待ちのまま放置されたカードはタイムアウトします。

**カードは実行前に「実行済み」として記録されます。** 途中でクラッシュしたカードを
無限に再実行しないためです。失敗したカードを再度流したいときは、Trello タブの
「実行済み記録を消す」を押してください。ドライランで流したカードも記録されます。

**実行は必ず 1 枚ずつです。** エージェントは 1 スレッドにつき 1 本のループしか回せないため、
`1 回あたりの最大カード数` を増やしても並列にはならず、直列に処理されます。

**「カードごとに新しいスレッドを開く」がオンだと、サイドバーの表示スレッドが切り替わります。**
手作業のチャット中に自動実行が走ると割り込まれるので、気になる場合は自動実行を切るか、
このオプションをオフにしてください。

## 実装

| ファイル | 役割 |
| --- | --- |
| `src/vs/workbench/contrib/void/common/trelloServiceTypes.ts` | 型定義、既定設定、プロンプト組み立て |
| `src/vs/workbench/contrib/void/browser/trelloService.ts` | Trello REST API 呼び出し、ポーリング、実行ループ |
| `src/vs/workbench/contrib/void/browser/trelloActions.ts` | コマンドパレット項目 |
| `src/vs/workbench/contrib/void/browser/react/src/void-settings-tsx/TrelloSettings.tsx` | Settings の Trello タブ |

設定は `GlobalSettings.trello` に入り、他の Orchestra 設定と同じく暗号化して永続化されます。
実行済みカード ID は `IStorageService`（`void.trello.processedCardIds`）に保存されます。
