# クラウドエージェントモード / 上級者モード (表示モード)

Orchestra は VS Code をベースにしているが、Orchestra の主役は「AI エージェントに仕事を任せること」であって、
自分でコードを書くことではない。左端のアイコン列、下端のステータスバー、ミニマップ、パンくず、
レイアウトボタン……どれも「エージェントにやってほしいことを伝えて、結果を確認する」には要らない。

そこで Orchestra には 2 つの **表示モード** がある。

| モード | 誰向け | 何が見える・どう動く |
| --- | --- | --- |
| クラウドエージェントモード (既定) | クラウドでエージェントに任せたい人 | Cursor の Agents 画面のように、クラウドエージェントの一覧・会話・変更だけをエディタ領域いっぱいに出す。IDE 的な部品は隠し、右のチャット (手元のエージェント) は強制的に隠す |
| 上級者モード (IDE 表示) | エージェントと並んで自分でもコードを触る人 | 通常の VS Code と同じ IDE の表示。右のチャットも使える。チャットモードや承認の設定も自分で選ぶ |

以前あった「エージェントモード」は廃止した。設定に `"agent"` が残っていても、クラウドエージェントモードとして扱う。

---

## 切り替え方

| 操作 | やり方 |
| --- | --- |
| 上級者モードにする | タイトルバー右の 🔧 ボタン / ホーム画面下部のリンク / コマンドパレット `Orchestra: 上級者モード (IDE 表示) に切り替える` |
| クラウドエージェントモードにする | タイトルバー右の ☁ ボタン / コマンドパレット `Orchestra: クラウドエージェントモードに切り替える` |
| クラウドエージェント ⇄ 上級者をトグル | `Ctrl+Alt+U` (macOS: `Cmd+Alt+U`) / チャット上部ヘッダーの 🤖 ボタン |
| 設定画面から選ぶ | Settings > **一般** > 表示モード (2 枚のカード) |

タイトルバー右には、今のモード以外へのボタンだけが出る (☁ クラウドエージェントモード / 🔧 上級者モード)。
クラウドエージェントモードのあいだは、☁ が「クラウドエージェントのパネルを前面に出す」ボタンになる。

実体は VS Code 設定 `orchestra.ui.mode` (`"cloud"` / `"pro"`) なので、settings.json に直接書いても構わない。
`"pro"` 以外の値 (未設定・廃止した `"agent"` / `"simple"` を含む) はすべてクラウドエージェントモードとして扱う。

## クラウドエージェントモードで変わること

クラウド (Division のサンドボックス) で動くエージェントだけを扱うための画面。Cursor の Agents 画面のように、エディタ領域いっぱいに
**左: エージェントの一覧 / 中央: 会話と入力欄 / 右: 変更ファイルと差分** の 3 列を出す。画面の中身は [クラウドエージェント](./cloud-agents.md) を参照。

### IDE 的な部品を隠す

- アクティビティバー (左端のアイコン列)・ステータスバー・レイアウトコントロール・コマンドセンターを隠す。
- ミニマップ・パンくず・グリフマージン・スティッキースクロールを off。
- 折り返し on、フォントを少し大きく (15px / 行間 1.6)。
- エクスプローラーのフォルダをまとめて折りたたまない (`a/b/c` 表示は分かりにくい)。

### レイアウト

- 入ったとき (切り替えたとき・起動時にこのモードだったとき): 右のチャット (補助バー)・サイドバー (ファイル一覧)・パネル (ターミナル) を閉じ、
  クラウドエージェントのパネルをエディタ領域に開く (固定タブ)。エディタを分割していれば、そのグループを最大化する。
- **チャットは強制非表示**: このモードのあいだは、ショートカット (補助バーの開閉など) や他のコマンドで右のチャットが開かれても、すぐに隠し直す。
  チャットを開くコマンド (`void.openSidebar` / `void.sidebar.open`) はこのモードでは何もしない。
- タイトルバーには ☁ (パネルを前面に出す、order 5)・Division プロジェクト (6)・コスト管理 (6.5)・カンバン (7)・🔧 (上級者モード、9) が出る。
- チャットから使っていた **Division プロジェクト** (ロールとモデルの割り当て)・**コスト管理** (コストの自動調整・クレジット・利用額)・**カンバン** は、
  パネル左の「ワークスペース」・タイトルバー・コマンドパレットから、IDE モードと同じ画面 (設定画面のタブ / カンバンのボード) をエディタ領域に開く。
  エディタとして開くので強制非表示とはぶつからず、チャットも戻らない。新しいエージェントの「プロジェクト」チップ、一覧の料金、カンバンの「クラウドで実行」で
  クラウドエージェントともつながっている ([クラウドエージェント](./cloud-agents.md#ワークスペースの道具-division-プロジェクト--コスト管理--カンバン))。
- パネルを閉じると、ホーム画面の代わりに「クラウドエージェントを開く / 新しいエージェント」と上級者モードへのリンクの画面が出る。
- ログインしていないときの **ログイン** は、チャットではなく設定画面 (ログインボタンがある) を開く。
- **出たとき** (上級者モードへ): チャットを戻し、入る前に開いていたサイドバー・パネルも戻す (ワークスペースごとに覚えている)。
  このモードが最大化したエディタグループも元に戻す。

## 仕組み (開発者向け)

実装は `src/vs/workbench/contrib/void/browser/orchestraUiMode.ts`。

見た目は **設定の既定値の上書き** (`IConfigurationRegistry.registerDefaultConfigurations`) で
実現している。ユーザーの settings.json には何も書き込まないし、ユーザーが同じキーを明示的に
設定していればそちらが勝つ。「クラウドエージェントモードのままミニマップだけ戻す」といったことも普通にできる。

- クラウドエージェントモードが既定なので、モジュール読み込み時点で既定値を登録しておく。
- 上級者モードのユーザーは `WorkbenchPhase.BlockStartup` の contribution で既定値を外す。
  レイアウトの描画より前に走るので、起動時にちらつかない。
- モードはコンテキストキー `orchestra.uiMode` (`cloud` / `pro`) にも流していて、タイトルバーのボタンの出し分けに使っている
  (`isCloudMode` / `isProMode` の ContextKeyExpr)。
- 設定値の解釈 (`parseOrchestraUiMode`) は `orchestraUiModeTypes.ts` にあり、React・ウォーターマーク・`sidebarPane.ts` でも同じものを使う。

クラウドエージェントモードのレイアウトは `OrchestraCloudModeLayout` (`WorkbenchPhase.AfterRestored`) が受け持つ。
設定 `orchestra.ui.mode` の変化を見て入る / 出るを判断し、このモードのあいだだけ `IWorkbenchLayoutService.onDidChangePartVisibility` と
`IViewsService.onDidChangeViewContainerVisibility` を購読して、補助バーやチャットのビューが表示されたら直後 (マイクロタスク) に隠し直す。
入る前のサイドバー・パネルの表示状態は `orchestra.ui.cloudMode.savedLayout` (ワークスペースのストレージ) に覚えておき、出るときに戻す。

手元のエージェント (チャット) の稼働状況は `IChatThreadService.onDidChangeStreamState` を見て、コンテキストキー
`orchestra.agentRunning` (LLM 生成中 / ツール実行中) と `orchestra.agentAwaitingUser` (承認待ち) に流す。
コマンドパレットの「エージェントを止める」「エージェントの確認待ちを見る」の precondition に使う。
