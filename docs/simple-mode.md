# かんたんモード / 上級者モード (表示モード)

Orchestra は VS Code をベースにしているが、初めて使う人にとって IDE の画面は情報が多すぎる。
左端のアイコン列、下端のステータスバー、ミニマップ、パンくず、レイアウトボタン……どれも
「まず AI に話しかけて何かを作る」には要らない。

そこで Orchestra には **表示モード** がある。

| モード | 誰向け | 何が見える |
| --- | --- | --- |
| かんたんモード (既定) | 初めての人・コードを書かない人 | ホーム画面 + AI チャット。IDE 的な部品は隠す |
| 上級者モード | VS Code に慣れている人 | 通常の VS Code と同じ IDE の表示 |

---

## 切り替え方

| 操作 | やり方 |
| --- | --- |
| 上級者モードにする | タイトルバー右の 🔧 ボタン / ホーム画面下部のリンク / コマンドパレット `Orchestra: 上級者モード (IDE 表示) に切り替える` |
| かんたんモードに戻す | タイトルバー右の ✨ ボタン / コマンドパレット `Orchestra: かんたんモードに戻す` |
| どちらかへトグル | `Ctrl+Alt+U` (macOS: `Cmd+Alt+U`) / チャット上部ヘッダーの ✨ ボタン |
| 設定画面から選ぶ | Settings > **一般** > 表示モード |

実体は VS Code 設定 `orchestra.ui.mode` (`"simple"` / `"pro"`) なので、settings.json に直接書いても構わない。

---

## かんたんモードで変わること

### レイアウト

- アクティビティバー (左端のアイコン列) とステータスバーを隠す。
- タイトルバー右に **ファイル一覧 / ターミナル / AI チャット** の開閉ボタンを出す。
  アクティビティバーが無い代わりに、ここから同じものを開ける。
- 初回起動時だけ、エクスプローラーとパネル (ターミナル) を閉じ、チャットをウィンドウ幅の 4 割ほどに広げる。
  以降はユーザーがドラッグした幅を VS Code が覚える。

### エディタ

- ミニマップ・パンくず・グリフマージン・スティッキースクロールを off。
- 折り返し on、フォントを少し大きく (15px / 行間 1.6)。
- エクスプローラーのフォルダをまとめて折りたたまない (`a/b/c` 表示は初心者に分かりにくい)。

### ホーム画面 (エディタが空のとき)

VS Code の透かし + ショートカット一覧の代わりに、日本語のホーム画面が出る。

- フォルダ未選択: 「フォルダを選ぶ → チャットに話しかける → できあがりを確認する」の 3 ステップと、
  **フォルダを開く** / **まずは AI に相談する** ボタン、最近使ったフォルダ。
- フォルダ選択済み: 「たとえば、こんなふうに」の例文 (押すとそのままチャットに送信) と、
  **チャットに話しかける** / **ファイル一覧を見る** / **ターミナルを開く** ボタン。

### AI チャット

- 最初の画面に「何を作りましょうか？」の一言と、初心者向けの例文 3 つ。
- 入力欄のプレースホルダを「例:「シンプルな TODO アプリを作って」」のような言葉に。
- モデル選択・プロジェクト選択などの細かい行は、入力欄左下の **詳しい設定** を押すまで畳む。

## 仕組み (開発者向け)

実装は `src/vs/workbench/contrib/void/browser/orchestraUiMode.ts`。

かんたんモードは **設定の既定値の上書き** (`IConfigurationRegistry.registerDefaultConfigurations`) で
実現している。ユーザーの settings.json には何も書き込まないし、ユーザーが同じキーを明示的に
設定していればそちらが勝つ。「かんたんモードのままミニマップだけ戻す」といったことも普通にできる。

- かんたんモードが既定なので、モジュール読み込み時点で既定値を登録しておく。
- 上級者モードのユーザーは `WorkbenchPhase.BlockStartup` の contribution で既定値を外す。
  レイアウトの描画より前に走るので、起動時にちらつかない。
- モードはコンテキストキー `orchestra.uiMode` にも流していて、タイトルバーのボタンの出し分けに使っている。

関連ファイル:

| ファイル | 役割 |
| --- | --- |

| `browser/parts/editor/editorGroupWatermark.ts` | ホーム画面 (`renderSimpleHome`) |

| `react/src/void-settings-tsx/UiModeSettings.tsx` | Settings > 一般 の表示モード |
