# Orchestra 紹介ループ動画

Orchestra を説明する 30 秒のループ動画（1920×1080 / 30fps / 音声なし）。
展示ディスプレイ、イベントブース、README や LP のヘッダー、SNS 用素材などにそのまま使えます。

| ファイル | 内容 |
| --- | --- |
| `orchestra-loop.mp4` | 書き出し済みの動画（H.264 / yuv420p） |
| `scene.html` | 動画の中身そのもの。1920×1080 の HTML アニメーション |
| `render.mjs` | `scene.html` を 1 フレームずつ撮って mp4 に書き出すスクリプト |

## 構成（30 秒）

| 時間 | 内容 |
| --- | --- |
| 28.4–5.0s | タイトル — Orchestra / 最強のマルチエージェントを搭載した次世代 AI IDE |
| 4.6–10.4s | 01 使いかた — プロンプトを 1 つ送るところまでを実演 |
| 10.0–18.0s | 02 オーケストレーション — Leader AI がタスク分解し、検索 → 設計 → コーディング → レビューが順に走る |
| 17.6–23.4s | 03 モデル — 6 プロバイダー / 38 モデルと `overrides` |
| 23.0–29.0s | 04 機能 — 自律型エージェント / @ コンテキスト / VS Code 互換 / MCP |

シーンは円環状のタイムラインに配置してあり、最後のシーンはタイトルへクロスフェードで戻ります。

## ループが途切れない理由

`scene.html` のアニメーションは CSS アニメーションではなく、**時刻 t の純粋な関数** `window.setT(t)` として書かれています。
背景の動きは周期 30 秒ちょうど、各シーンの表示時間は `t mod 30` で決まるため、
`setT(0)` と `setT(30)` は必ず同じ絵になります。つまり継ぎ目は原理的に発生しません。

同時に、これは「1 フレームずつ `setT()` を呼んでスクリーンショットを撮る」だけで
タイミングのブレなく決定論的に書き出せる、ということでもあります。

## 書き出しかた

```bash
cd docs/loop-video
npm install playwright ffmpeg-static     # 初回のみ
node render.mjs                          # -> orchestra-loop.mp4
```

初回実行時に Noto Sans JP を `~/.local/share/fonts` へ入れて `fc-cache` を走らせます
（見つからない場合は IPAGothic にフォールバックします）。

途中の絵を静止画で確認したいときは:

```bash
node render.mjs --preview 0,6.5,13.5,20,25.5   # preview-<秒>s.png を書き出す
```

## 中身を変えるには

文言・モデル名・シーンの尺は `scene.html` だけで完結しています。

- テキスト: 各 `<section class="scene">` の中身
- 尺と並び順: `SCENES` 配列の `start` / `dur`（合計の長さは定数 `D` = 30 秒）
- 演出: 各シーンの `s1fn`〜`s5fn`。引数はそのシーンの経過秒 `tl`

`D` を変えたときは `render.mjs` の `DURATION` も同じ値に合わせてください。

ブラウザで `scene.html` を直接開くと 0 秒時点の絵が出ます。
DevTools のコンソールから `setT(13.5)` のように呼べば任意の時刻を確認できます。
