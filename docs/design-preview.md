# DESIGN.md と「Markdown + HTML プレビュー」

Division のデザイナーロールは、デザイン仕様を **`.division/DESIGN.md`** に書き出します。
DESIGN.md は普通の Markdown ですが、見た目に関わる部分は ```` ```html ```` ブロック、デザイントークンは ```` ```css ```` ブロックで書きます。

````markdown
## デザイントークン

```css
:root {
  --color-accent: #6366f1;
  --radius-md: 8px;
}
```

## ボタン

```html
<!-- プライマリボタン -->
<button style="background:var(--color-accent);border-radius:var(--radius-md);color:#fff">保存</button>
```
````

- ```` ```html ```` の中身は、そのまま表示できる HTML です。断片 (スニペット) でも、`<!DOCTYPE html>` から始まる完全な文書でもかまいません。
- 同じ DESIGN.md 内の ```` ```css ```` ブロックは、すべての HTML プレビューに (スニペット自身のスタイルより前に) 読み込まれます。`:root` のトークンはどのブロックからでも `var(--...)` で使えます。
- ブロックの名前は、最初の HTML コメント (`<!-- ... -->`)、`<title>`、最初の見出しの順に探して付けます。

## プレビューを開く

| 方法 | 内容 |
| --- | --- |
| コマンドパレット | 「Markdown + HTML プレビュー」 (`orchestra.designPreview.open`) |
| エディタ右上のボタン | Markdown ファイルを開いているときに表示される (プレビューアイコン)。横に並べて開く |
| キーボード | `Ctrl+Shift+Alt+V` (macOS は `Cmd+Shift+Alt+V`) |
| 通知 | デザイナーが `.division/DESIGN.md` を作成・更新すると「デザイン仕様 (DESIGN.md) を作成しました」と表示され、「プレビュー」で開ける |
| チャット | フローレビューのカード / ロール出力パネルで DESIGN.md に「プレビュー」が付く |

対象のファイルは、コマンドに URI を渡した場合はそのファイル、渡さなければアクティブなエディタの `.md`、
それも無ければ最初のワークスペースフォルダの `.division/DESIGN.md` です。

プレビューはファイルの保存・エディタでの入力に合わせて自動で更新されます (スクロール位置は保持)。
プレビューを開いている間は、DESIGN.md 更新の通知は出しません。

## HTML ブロックの表示

各 ```` ```html ```` ブロックには、次のツールバーが付きます。

- **プレビュー / コード / 両方** — 描画結果、シンタックスハイライトしたソース、またはその両方を表示します (既定はプレビュー)
- **編集** — 描画された UI をその場で編集します (下記)
- **新しいウィンドウで開く** — ブロックを一時ファイルに書き出して外部ブラウザで開きます

プレビューは `sandbox="allow-scripts"` の iframe で表示します。スニペット内のスクリプトは動きますが、エディタ本体や他のブロックには触れられません。
iframe の高さは内容に合わせて自動調整されます (最大 1600px、それを超えると iframe 内でスクロール)。

## ビジュアル編集

「編集」を押すと、そのブロックが編集モードになります (一度に編集できるのは 1 ブロック)。

- テキストはクリックしてそのまま書き換えられます
- 要素をクリックすると選択され (青い枠)、プロパティパネルで **文字色・背景・フォントサイズ・パディング・マージン・角丸・幅・高さ** を変更できます (要素のインライン style に書き込みます)
- **親要素** で選択を親に広げる、**複製**、**削除**
- **元に戻す** (`Ctrl+Z`) で 1 操作ずつ戻せます
- **保存** (`Ctrl+S`) で DESIGN.md の **そのブロックの中身だけ** を書き換えます。ほかの行には触れません
- **キャンセル** で編集内容を破棄します

保存される内容は、スニペットなら `<body>` の中身、完全な文書なら文書全体です。
編集用に付けた属性 (`contenteditable`、選択枠) や、注入したトークン CSS は取り除いてから保存します。
DESIGN.md をエディタで開いていて未保存の変更がある場合は、ディスクではなくエディタの内容に反映します (保存はご自身で)。
編集中に DESIGN.md のそのブロックが別の場所で書き換えられていた場合は保存せず、エラーを表示します。

編集中の iframe は `sandbox="allow-same-origin"` (スクリプトなし) に切り替わるため、ブロック内のスクリプトは動きません。
編集中はファイルが変わってもプレビューを再読み込みせず、保存またはキャンセルのあとに最新の内容を反映します。

## 制限

- HTML ブロック内の画像は `https:` か `data:` の URL を使ってください (iframe は隔離されているため、相対パスのローカル画像は読めません。「新しいウィンドウで開く」では DESIGN.md のフォルダ基準で解決されます)
- Markdown 本文 (HTML ブロック以外) に直接書いた生の HTML は、安全のため sanitize されます (`<script>` などは削除)
- 実装: `src/vs/workbench/contrib/void/browser/designMdPreview.ts` (webview / コマンド / 通知)、`src/vs/workbench/contrib/void/common/designMdPreviewHtml.ts` (HTML 生成・書き戻しの純粋関数)
